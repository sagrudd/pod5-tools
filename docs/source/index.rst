pod5-tools documentation
========================

``pod5-tools`` is a planned Rust command-line and library toolbox for
discovering, inspecting, verifying, subdividing, and replaying Oxford Nanopore
POD5 data collections.

The project is sponsored by Mnemosyne Biosciences and is intended for
bioinformatics service providers, DNA sequencing core facilities, and software
developers who need reliable local-infrastructure tooling around long-read raw
signal data.
